# CyberSaathi B2C

AI-driven fraud recovery app.

**Stack:** Flutter (frontend) · FastAPI (backend) · PostgreSQL (database)

## Folder structure

- `backend/` — FastAPI service: auth, API, database models, migrations, tests
- `frontend/` — Flutter mobile app
- `docs/` — project and architecture documentation
- `.github/workflows/` — CI pipelines

## How to run

See [backend/README.md](backend/README.md) for backend setup and run instructions.
